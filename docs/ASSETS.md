# Asset provenance

- Nori's proportions, face, scarf, pack and animation code are original to this
  project. The 3D meshes currently use Unreal's built-in basic shapes.
- World composition, palette progression, modular placement rules, route layout,
  Echo, enemy behaviors and dialogue were authored for this project.
- `Web/public/journey.svg` is original vector artwork generated by
  `Scripts/draw_title.py`. It is title-page illustration, not captured gameplay.
- `Web/public/mark.svg` is an original cake mark.
- The 23 WAV files are original deterministic synthesis from
  `Scripts/generate_audio.py`; no recordings, sample packs or external melodies.
- Browser typography uses installed system fonts; no external font/CDN requests.
- Unreal Engine and its engine assets remain subject to Epic's license. They are
  not relicensed by this repository.
- Epic's Pixel Streaming npm libraries are external MIT-licensed dependencies;
  their package licenses and notices must be retained in distribution.
- No Crash Bandicoot characters, art, branding, animation, audio, collectibles,
  code or extracted game assets are included.
- No visual reference image was available in the attachments. Only the written
  brief was used.
